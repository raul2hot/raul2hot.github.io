Oriole is a torrent file browser, downloader and media player for Android. It starts playing while it downloads, plays the formats other apps refuse, and lets you decide where the files come from.

What it actually does

A client, not a catalogue. It searches an index, then talks to the swarm.

  • Streams while it downloads. Tap a result and the picture starts, and the file arrives behind it, ordered around the playhead.
  • Plays what browsers won't. Built on libVLC: AVI/Xvid, MKV, AC-3, E-AC-3, DTS, and the rest, with sound.
  • Casts to the TV. Sends playback to a Chromecast, or straight to a DLNA smart TV. Hands the file over directly when the set can decode it, converts on the phone when it can't.
  • Tracks a topic. Save a standing question and it re-runs on the schedule you pick, merging whatever is new. Optional, and it uses your own AI key.
  • Real audio player. Album art from the release itself, lock-screen controls, background playback.
  • Browse inside a torrent. Every file listed, video, audio, images and text, with the rest saved out to your phone.
  • Bookmarks that keep working. A saved result stores the whole record, so it still plays when the index has moved on.
  • Ask in your own words. Optional AI search, using your own API key, that reads the index and picks for you.
  • Careful with your data plan. Wi-Fi-only by default, and it says out loud that streaming a film downloads a film.

You choose where files come from

The first screen asks. Nothing is contacted until you answer it.

The public domain library

One tap, no account. Films, music, books and software that are free for everyone: public domain and openly licensed works, curated by the developer.

Your own server

Point Oriole at any index that speaks the open protocol, one you run or one you trust. The app is the same either way; only the source changes.

The index protocol is published under the MIT license, so anyone can implement it: torrent-stream-protocol.
